# Описание курса

Курс лабораторных работ по бэкенд-разработке для направления 09.03.04 «Программная инженерия».

## Технологии

В зависимости от лабораторной работы используется один из стеков:
- **Node.js + Express** — для HTTP-серверов и REST API
- **Python + Flask** — альтернативный стек с тем же функционалом
- **SQL** (SQLite/PostgreSQL) — для лабораторных, связанных с базами данных

## Формат отчёта

Каждая лабораторная работа сопровождается отчётом в формате Markdown (`README.md` внутри папки лабораторной), содержащим:

1. Титульный лист (ФИО, группа, вариант)
2. Цель работы
3. Теоретическое обоснование
4. Выполнение практического примера
5. Выполнение индивидуального задания
6. Ответы на контрольные вопросы
7. Вывод
8. Список источников

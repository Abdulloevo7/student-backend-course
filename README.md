## Как добавить новую лабораторную

1. Перейдите в соответствующую папку `labN-.../`
2. Замените заглушку в `README.md` на полный отчёт (по шаблону из `common/templates/lab-report-template.md`)
3. Добавьте код сервера (`app.js` / `app.py`) и файл зависимостей (`package.json` / `requirements.txt`)
4. Сложите скриншоты в `screenshots/`
5. Обновите статус в таблице выше в этом файле
6. Закоммитьте и запушьте: `git add . && git commit -m "Lab N: <тема>" && git push`

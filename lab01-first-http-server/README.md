## Теоретическое обоснование

Бэкенд — это серверная часть веб-приложения, отвечающая за обработку запросов клиентов, работу с данными и бизнес-логику. Взаимодействие клиента и сервера строится по модели «клиент-сервер»: клиент (браузер) отправляет HTTP-запрос по определённому адресу — эндпоинту (endpoint), а сервер обрабатывает его через маршрут (route) и возвращает HTTP-ответ.

Метод **GET** используется исключительно для получения данных и не должен изменять состояние сервера (идемпотентность). Ответы сервера часто оформляются в формате **JSON** — текстовом формате обмена данными, ставшем стандартом для REST API благодаря простоте чтения как человеком, так и машиной.

Для ускорения разработки применяется автоматический перезапуск сервера при изменении кода — в экосистеме Node.js для этого используется пакет **nodemon**, который отслеживает изменения файлов и перезапускает процесс `node` без ручного вмешательства.

### Консольное логирование

Реализовано middleware, логирующее в консоль метод, URL и время каждого запроса:

```js
app.use((req, res, next) => {
  console.log(`[${new Date().toISOString()}] ${req.method} ${req.url}`);
  next();
});
```

## Ответы на контрольные вопросы

1. **Что такое клиент-серверная архитектура?**
   Модель взаимодействия, при которой клиент (браузер, приложение) отправляет запросы, а сервер их обрабатывает и возвращает ответы. Клиент инициирует обмен, сервер — обслуживает запросы.

2. **Какой протокол используется для общения клиента и сервера в вебе?**
   HTTP (HyperText Transfer Protocol), а также его защищённая версия HTTPS.

3. **Что такое эндпоинт (endpoint)?**
   Конкретный адрес (URL) в сочетании с HTTP-методом, по которому клиент обращается к серверу за ресурсом, например `GET /api/users`.

4. **Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое код состояния?**
   Запрос состоит из строки метода и пути, заголовков и (опционально) тела. Ответ содержит строку статуса, заголовки и тело. Код состояния (status code) — трёхзначное число, показывающее результат обработки запроса, например `200 OK`, `404 Not Found`, `500 Internal Server Error`.

5. **Что такое JSON? Почему он популярен в веб-разработке?**
   JSON (JavaScript Object Notation) — текстовый формат обмена данными на основе пар «ключ-значение». Популярен из-за простоты чтения человеком, компактности и нативной поддержки в JavaScript, а также широкой поддержки во всех языках программирования.

6. **Как запустить сервер на Node.js?**
   Установить Node.js, инициализировать проект (`npm init -y`), установить нужные зависимости (`npm install express`) и запустить файл сервера командой `node app.js` или через npm-скрипт (`npm start`).

7. **Что такое автоматический перезапуск сервера и зачем он нужен? Какой пакет используется для Node.js?**
   Это механизм, который отслеживает изменения в файлах проекта и автоматически перезапускает сервер, избавляя разработчика от необходимости делать это вручную. Для Node.js используется пакет `nodemon`.

8. **Какие коды состояния HTTP вы знаете? За что отвечает код 404?**
   Основные группы: `2xx` — успех (`200 OK`, `201 Created`), `3xx` — перенаправление (`301`, `302`), `4xx` — ошибка клиента (`400 Bad Request`, `401 Unauthorized`, `404 Not Found`), `5xx` — ошибка сервера (`500 Internal Server Error`). Код `404` означает, что запрошенный ресурс/маршрут не найден на сервере.

9. **Что такое middleware в Express?**
   Функция, которая получает доступ к объектам запроса (`req`) и ответа (`res`) и может выполнять код, изменять эти объекты или передавать управление следующему middleware через вызов `next()`. Используется, например, для логирования, аутентификации, обработки ошибок.

10. **Как получить параметр из URL-пути в Express?**
    Через объект `req.params`. Например, для маршрута `app.get('/api/tasks/:id', ...)` значение параметра доступно как `req.params.id`.
